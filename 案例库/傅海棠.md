# 傅海棠：一个农民的亿万传奇

> 初中毕业的山东农民，养过猪、种过大蒜、做过小贩。在期货市场熬了九年、最高负债300万后，用约2-3万本金，18个月内做到了1.2亿（约4000-6000倍）。2016年再度用1500万做到10亿（约67倍）。
>
> 业界称他为**「农民哲学家」**和**「北丐」**。

---

## 📋 基本信息

| 项目 | 详情 |
|------|------|
| 出生 | 1967年，山东济宁农村 |
| 学历 | 初中毕业 |
| 早期经历 | 养过六年猪，种过棉花、大蒜、小麦，做过毛皮/塑料小贩 |
| 入市时间 | 2000年（33岁） |
| 成名战役 | 2009年大蒜电子盘 + 2010年棉花期货 |
| 最高纪录 | 2016年斩获超10亿利润 |
| 著作 | 《一个农民的亿万传奇》 |
| 现况 | 仍住山东济宁农村，用自有资金交易，不为他人理财 |

---

## 📖 完整故事

### 一、一张踩在脚下的破杂志（1997年）

1997年，30岁的傅海棠去亲戚家串门，**踩到地上的一张破烂杂志**。捡起来翻了翻，一个介绍期货的小栏目吸引了他：

> 「期货以标准化合约进行交易，保证金只需5%。」

傅海棠一下子被击中了。

他之前一直想做"囤积居奇"的生意——便宜的时候买入，涨价后卖出。但一个农民哪来大笔资金？而期货的5%保证金，意味着用5块钱就能撬动100块钱的货。**这就是杠杆。**

"期货"这个念头，从此刻在他脑中生根发芽。

---

### 二、十年炼狱（2000-2009）

2000年，经朋友介绍，33岁的傅海棠终于开了期货账户。

此后**整整九年**，他的生活是这样的：

- 每天从农村老家**骑自行车到镇上，再搭公交车到济宁市里**的期货营业部看盘
- 风雨无阻，坚持了八九年
- 做他熟悉的大豆，但**赚少亏多**，资金在10万到30万之间起伏

他自己分析亏损原因：
1. **新手不懂行，必定要交学费**——对市场认知不足
2. **熟悉基本面，但不懂游戏规则**——不理解市场的波动规律
3. **有钱了就开始麻痹**——风险偏好变大，仓位过重

期间错失的两次大行情：
- **2003年大豆**：看对大牛市，结果交易所临时修改规则导致缩板，盈利大幅缩水
- **2007年**：看对行情但因怕错过机会匆忙满仓，遭遇洗盘回调被甩下车

更致命的是——他带着亲朋好友一起做期货，**承诺兜底，还按年化30%支付利息**。九年利滚利，负债滚到了**近300万元**。

此时的傅海棠，40多岁了。农民出身、初中学历、负债300万。按任何标准，这都是一个彻底的失败者。

但他没放弃。他在等一个机会：

> **「物极必反。」**

---

### 三、一战封神：大蒜之战（2009年）

#### ① 发现机会

此前两年，大蒜市场已跌入深渊：

| 年份 | 大蒜行情 |
|------|---------|
| 2007年 | 收购价约0.7元/斤，加冷库费成本约0.85元，最终售价仅0.1元左右。冷库商巨亏，纷纷弃货跑路 |
| 2008年 | 蒜农也陷入巨亏——种植成本1元以上，售价仅0.18-0.25元/斤。种植信心彻底崩溃 |

市场上的声音出奇一致：**冷库里陈蒜够吃三年，大蒜永远不会涨了。**

#### ② 实地调研

2008年底到2009年初，傅海棠**驱车数万公里**，跑遍山东金乡、江苏邳州、河南中牟、河南杞县等所有大蒜主产区。

他的调研方式非常"土"：
- 请当地贸易商和冷库商吃饭聊天
- 蹲在田间地头看蒜苗长势
- 挨个村子打听种植面积
- 连小商贩和农民家里的"隐性库存"都不放过

**调研得出的核心数据：**
- 大蒜播种面积下降约 **30%**
- 单产减少约 **20%**（出苗后出现烂根、大面积死亡）
- 总产量预计下降约 **40%**
- 他所在的村子，退种率高达 **99%**

所有人都看空，但他问了贸易商一句话：

> **「大蒜还兴不兴吃？兴吃就得涨！」**

#### ③ 入场：寿光电子盘（3月 → 5月初）

> **备注：大蒜电子盘**是现货电子交易平台，规则类似期货但不完全一样。保证金约**20%**（约5倍杠杆），交易标的是干蒜，按吨计价。

| 时间 | 事件 |
|------|------|
| 2009年3月 | 用约 **2-3万元**（期货豆粕盈利）入场寿光电子盘，以约 **840元/吨** 做多。同期现货陈蒜仅200元/吨，市场预期新蒜400元，840元在旁人看来是"天价" |
| 3月-4月中 | 价格在700-900元震荡，傅海棠持续把期货盈利转入电子盘加仓。资金滚到约 **20万** |
| 4月底 | 蒜薹上市，因大幅减产 + 需求激增，田间收购价飙到1.7-1.8元/斤（创历史新高，此前最高仅1.2元） |
| 五一后 | 电子盘连续涨停，资金滚到约 **70万** |

#### ④ 意外：被强制平仓

2009年4月22日，寿光交易所突然引入**"集中代为转让合同制度"**——连续三个涨跌停板就强制协议平仓（傅海棠认为这是空头与交易所联手搞的规则，专门保护空头）。

五一后开盘：
- **第一天**：逐步涨至涨停封板
- **第二天**：空头操控——先在跌停板成交10万手，随后封涨停，导致收盘虽涨停但**结算价在跌停板附近**
- **第三天**：再度涨停，触发集中转让，强制平仓在约 **1100元/吨**

傅海棠后来估计，**如果不被强制平仓，做到最后可能是1-2个亿。**

#### ⑤ 转战龙鼎电子盘（5月 → 6月）

被强平当天，傅海棠立刻在**日照龙鼎公司**开户，次日把70万全部转入：

| 时间 | 操作 |
|------|------|
| 周三 | 在 **1500元/吨** 开仓30% |
| 周四 | 跌到 **1450元/吨**，再开30% |
| 周五 | 跌到 **1400元/吨**，满仓买入 |
| 周末 | 现货每吨暴涨400元（鲜蒜从0.45元/斤涨到0.65元/斤） |
| 周一-周三 | 电子盘**连续三个涨停** |

此后他执行了一个关键策略 —— **「赚了就走，落袋为安」**：

> 每赚50万就出金50万，账户始终只保留50-100万操作资金。

#### ⑥ 最终战果

| 项目 | 详情 |
|------|------|
| 龙鼎盘价格 | 从1450元/吨涨至约**4000元/吨**（同期现货已到8000+） |
| 累计出金 | 约 **600万元** |
| 后果 | 7月龙鼎盘崩盘，账户剩余约100万取不出来 |

#### ⑦ 为什么涨得这么猛？

**甲流（H1N1）来了。** 2009年3-4月甲流全球爆发，各国媒体铺天盖地宣传"大蒜有助于预防甲流"，民间疯传大蒜素抗病毒。出口暴增 + 国内消费井喷，"三年吃不完的库存"**一个月就被抢光了**。

大蒜现货从 **0.1元/斤** 涨到最高 **3元/斤以上**，涨幅约 **30倍**。

> 甲流这个黑天鹅，傅海棠调研时并不知道。但他确认库存远低于预期 + 减产已成定局 —— **有没有甲流都会涨，甲流只是把涨幅和速度拉满了。**

#### ⑧ 算账：200-300倍是怎么来的

很多人疑惑：电子盘价格从840涨到4000，约涨了4.8倍，5倍杠杆算下来也就24倍，怎么变成200-300倍的？

答案是**复利滚动**：

1. 入场后不断把期货盈利转入加仓（并非一把梭就躺平）
2. 在寿光盘被强平后换平台重新建仓
3. 行情启动后滚动操作（蒜薹上市那波从20万冲到70万就是3.5倍）
4. 多次复利叠加

> **2-3万 → 20万（约8-10倍）→ 70万（约3.5倍）→ 600万（约8.6倍）**
>
> 总回报约200-300倍。这得益于杠杆 + 换平台重新建仓 + 在趋势中持续加仓的叠加效应。

---

### 四、棉花之战：600万到1.2亿（2010年）

2009年底到2010年，傅海棠拿着大蒜赚来的600万，转战**棉花期货**。

当时棉花种植面积因灾害严重萎缩，供需极度紧张。他在**13000元/吨**的低位做多，一路拿到**29600元/吨**平仓。

**18个月，从约2-3万到1.2亿。约4000-6000倍。**

---

### 五、2016年：70倍再创奇迹

经历2013-2015年的回撤，此前赚的1亿多本金一度亏到只剩约1500万。

2016年，他看准商品期货大行情，全年轮番做多黑色系（螺纹钢、铁矿石）、棉花、豆粕、玻璃等品种，**资产从1500万增长到约10亿，约67倍收益。**

---

## 🧠 核心方法论：盈利三板斧

傅海棠**从不看K线图、从不做技术分析**。他认为技术分析是"从结果推结果"。

他只信一件事：**供需。**

### 第一板斧：调研定方向

> 「功夫在盘外，不在电脑中，不在K线中。」

- 开车跑遍主产区，看种植面积、作物长势、仓库库存
- 不只看大仓库，连小商贩、农民家里的隐性库存都不放过
- 做工业品就下工厂、跑矿区，查产能、成本、订单
- 种植季、生长季、收获季，**三个季节都要实地跑**

### 第二板斧：极端定仓位

只在**三个条件同时满足**时才重仓（缺一不可）：

| 条件 | 含义 |
|------|------|
| ① 价格跌破全行业生产成本 | 生产者普遍深度亏损、不愿再生产 |
| ② 供求出现极致失衡 | 供需缺口无法在短期内弥补 |
| ③ 市场情绪极致冰点 | 全市场一致看空、无人敢做多 |

一年甚至几年才做一次大行情。看不懂的时候就空仓。

### 第三板斧：天道定信心

> 「看对是最好的风控。」

- 只要调研结论没错、供求核心逻辑没有反转，**短期价格波动只是噪音**
- 一旦发现判断失误、供求逻辑发生根本性反转 → **无条件认错离场**
- 止损不是价格止损，而是**逻辑止损**

---

## 🧬 他的投资哲学：天道

傅海棠把他的方法叫**「天道」**：

> 市场运动遵循天道规律，价格趋势源于供求动力。物极必反、阴阳平衡——这是不以人的意志为转移的自然规律。

### 做多情结

他坚定偏好做多，极少做空：

| 做多 | 做空 |
|------|------|
| 亏钱有底线（最多归零） | 亏钱无上限 |
| 赚钱无天花板 | 赚钱有上限（最多跌100%） |
| 低价里藏着暴利 | 高位做空空间有限 |

> 「价格从2块涨到4块只翻1倍，从1毛涨到2块翻了20倍——**低价里藏着暴利。**」

### 入场信号（做多）

- 价格最低的、库存最少的、生产者亏损最大的品种
- "贵出如土，贱取如珠玉"——高位打死不做多，低位打死不做空
- 牛市基础：① 对生产者造成严重打击 ② 库存急剧减少

### 三大判断维度

| 维度 | 内容 |
|------|------|
| 供求决定趋势 | 这是行情的根——多了还是少了？ |
| 价值决定区间 | 价格围绕成本波动，成本是铁底 |
| 宏观决定人气 | 大势氛围影响短期情绪 |

## ⚠️ 血的教训

### 教训一：整整亏了九年

入市前九年——**整整九年**——持续亏损。这其中的心理压力、家庭压力、债务压力，外人无法想象。他自己说：到了**绝望边缘**。

**启示：** 他的路不可复制。不是每个人都能在持续亏损九年后还活着。

### 教训二：替人管钱，负债300万

自己亏几十万也就罢了。最致命的是**带亲朋好友一起做**，承诺兜底 + 按年化30%付利息。九年利滚利，负债近300万。

**启示：** 永远不要替别人管钱，永远不要承诺保本。这也解释了为什么他成名后**绝不为他人理财、不发产品、不培养交易员**。

### 教训三：2008年铜——贪婪吃掉了所有利润

看准做空铜，国庆长假外盘暴跌，国内三板强平。提前平仓后因为**贪婪**没接上仓位，又去抄底越抄越低——盈利全部吐回去。

**启示：** 赚了钱之后的贪婪，比亏了钱之后的恐惧更致命。

### 教训四：2012年豆粕——持仓太大被围剿

资金占比过大，持仓占到豆粕市场总持仓量的**八分之一**。被空头盯上围剿，回撤惨烈。

**启示：** 你的仓位本身就是市场的一部分。持仓大到一定程度，你就从"捕猎者"变成了"猎物"。

### 教训五：2014年底——几近腰斩

做多螺纹钢、甲醇、PTA、铁矿石等品种，账户从6300万浮亏至2000多万，几近腰斩（好在后来一个月内反弹至9600万）。

**启示：** 即使判断正确，极端波动也能让你提前出局。仓位管理永远是生死线。

## 💬 他对期货的真实态度

一个靠期货赚了十几亿的人，对期货是这样的：

> **「期货赚钱的概率，连千分之五都不到。」**

> **「拒絕亲朋好友踏入这个市场。子子孙孙都不准进入。」**

他形容期货交易的生活：

> **「孤独、无聊、空虚、恐惧、紧张。」**

苦大于乐，但人在围城，已经出不去了。

成名后：
- 绝不为他人理财，不接任何外部资金
- 不发产品，不培养交易员
- 只用自有资金交易
- 大部分时间仍住在山东济宁农村老家

## 📊 完整经验总结

| 维度 | 经验 ✅ | 教训 ❌ |
|------|---------|---------|
| **方法论** | 只看供需基本面，不看K线 | 技术分析是"从结果推结果" |
| **信息获取** | 亲自跑田间地头、工厂矿山（数万公里调研） | 坐在电脑前永远找不到真相 |
| **入场时机** | 只在价格跌破成本 + 供需失衡 + 情绪冰点时进场 | 频繁交易、追涨杀跌 |
| **仓位管理** | 确定性极高才重仓；边赚边出金，落袋为安 | 持仓太大变成猎物；满仓被洗盘甩下车 |
| **离场纪律** | 逻辑止损（判断错就无条件走）；不设价格止损 | 贪婪导致赚了不跑、越抄越低 |
| **他人资金** | 绝不为他人理财，只用自己的钱 | 替亲友管钱，背300万债——血的教训 |
| **对待市场** | 物极必反，相信天道 | 期货成功概率不足千分之五 |
| **杠杆** | 做多亏钱有底线，做空亏损无限 | 浮盈加仓，一把亏光 |
| **风险意识** | "亏钱是大概率事件，赚钱是小概率事件" | "有钱就麻痹了，对风险意识不够" |
| **核心本事** | 十几年的务农经验转化为对农产品供需的直觉 | 这种直觉是时间积累出来的，不可速成 |

## 🔑 对普通人的启示

### 1. 他的成功不可复制

傅海棠能成，不是因为他聪明，而是因为他**对农产品有十几年的直接经验**——养过猪、种过大蒜棉花、做过小贩。这些"土知识"在实地调研时变成了别人没有的直觉。

没有这种积累的人，照搬他的方法，**大概率先亏九年然后就没有然后了**。

### 2. 但思维方式可以学

"物极必反""低价买入""供需决定价格"——这些思维用在**做生意、投资、选行业**上同样有效。当一个行业所有人都亏钱、没人愿意干的时候，就是机会在酝酿。

### 3. 调研比聪明重要

傅海棠跑的数万公里、问的每一个蒜农、看的每一个仓库——这才是他真正的护城河。

> **比别人多知道一点点，就是信息差。信息差就是利润。**

### 4. 杠杆可以暴富，也可以暴毙

傅海棠能扛住九年亏损等到爆发，因为他在农村种地养猪，生活成本极低。但大多数人拿工资在城里供房贷养家——**你扛不住一个甚至几个周期。**

### 5. 别碰期货

> 连赚了十几亿的人都告诉你——**子子孙孙不要碰。**

这不是谦虚，是过来人最真诚的警告。普通人想积累财富，知识付费、数字资产、信息差套利、指数基金定投……这些路径远比期货靠谱一万倍。

> 傅海棠的成功，本质上是一个农民用最朴素的方法——**看供需、算成本、跑现场、等极端、信规律**——在极高杠杆的市场里，把认知兑现到极致的故事。
>
> 但别忘了：
> 他在这个市场里，**熬了整整九年，负债300万**，才等来那一年半的爆发。
>
> **这条路他人勿入。但这条路背后的思维方式，值得每一个想致富的普通人深思。**
